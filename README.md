# TAUsers - Приложения для заказчиков

Веб-приложение для пользователей сайта [tashi-ani.ru](https://tashi-ani.ru)

## Описание

TAUsers - это набор веб-приложений для заказчиков и пользователей платформы tashi-ani.ru. Приложение позволяет:

- Просматривать профиль пользователя
- Отправлять заявки и запросы
- Управлять подписками
- Взаимодействовать с платформой

## Структура проекта

## Запуск приложения

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/DGersmv/TAUsers.git
cd TAUsers
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# С помощью Python 3
python -m http.server 8000

# С помощью Node.js (http-server)
npx http-server -p 8000
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`
