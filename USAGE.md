# Инструкция по использованию TAUsers

## Быстрый старт

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/DGersmv/TAUsers.git
   cd TAUsers
   ```

2. **Запуск приложения**
   
   Просто откройте `index.html` в браузере или запустите локальный сервер:
   
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx http-server -p 8000
   ```

3. **Перейдите в браузере**
   ```
   http://localhost:8000
   ```

## Структура приложения

```
TAUsers/
├── index.html              # Главная страница
├── pages/                  # Внутренние страницы
│   ├── profile.html       # Профиль пользователя
│   ├── requests.html      # Управление заявками
│   └── about.html         # Информация о проекте
├── css/
│   └── style.css          # Все стили приложения
├── js/
│   └── app.js             # Логика приложения
└── assets/                # Статические ресурсы
```

## Функционал

### 1. Профиль пользователя (`pages/profile.html`)
- Просмотр информации профиля
- Редактирование данных пользователя
- Просмотр статистики (заявки, активность)

### 2. Заявки (`pages/requests.html`)
- Создание новых заявок
- Просмотр списка всех заявок
- Фильтрация по статусу
- Просмотр деталей заявки

### 3. Главная страница (`index.html`)
- Обзор возможностей
- Быстрый доступ к основным функциям
- Навигация по разделам

## Хранение данных

Приложение использует **LocalStorage** браузера для хранения:
- Данных профиля пользователя
- Списка заявок
- Настроек приложения

⚠️ **Примечание**: Данные хранятся локально в браузере. При очистке кэша браузера данные будут удалены.

## Типы заявок

1. **Техническая поддержка** - вопросы по работе сервиса
2. **Запрос контента** - запросы на добавление аниме
3. **Вопрос по подписке** - вопросы об оплате и подписках
4. **Обратная связь** - предложения и отзывы
5. **Другое** - прочие вопросы

## Статусы заявок

- 🆕 **Новая** - заявка только что создана
- ⏳ **В обработке** - заявка рассматривается
- ✅ **Завершена** - заявка выполнена
- ❌ **Отклонена** - заявка отклонена

## Разработка

### Редактирование стилей
Все стили находятся в файле `css/style.css`. Файл организован по разделам:
- Reset и базовые стили
- Навигация
- Компоненты (кнопки, формы, таблицы)
- Адаптивный дизайн

### Редактирование логики
Основная логика в `js/app.js`:
- `TAUsers.getCurrentUser()` - получить текущего пользователя
- `TAUsers.updateUserProfile(data)` - обновить профиль
- `TAUsers.requestsDB.*` - методы работы с заявками
- `TAUsers.showNotification(msg, type)` - показать уведомление

## Адаптивность

- 📱 Мобильные телефоны (до 768px)
