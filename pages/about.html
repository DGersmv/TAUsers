О проекте TAUsers

TAUsers - это веб-приложение для управления заявками и профилями пользователей платформы tashi-ani.ru.

Возможности

  • Создание и управление профилем пользователя
  • Отправка заявок различных типов
  • Отслеживание статуса заявок
  • Просмотр статистики активности
  • Адаптивный дизайн для всех устройств

Технологии

  • HTML5 - структура страниц
  • CSS3 - стилизация и адаптивный дизайн
  • JavaScript (Vanilla JS) - логика приложения
  • LocalStorage API - хранение данных на клиенте
